# Mini 4 Pro Mapping Planner (v0.2)

เว็บแอปวางแผนบินทำแผนที่สำหรับ DJI Mini 4 Pro + RC-N2
วาดขอบเขตบนภาพดาวเทียม → คำนวณเส้นบิน → ตรวจเงื่อนไข → สร้างไฟล์ KMZ สำหรับ DJI Fly

## เปิดใช้งาน
- เปิด `index.html` ในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ตสำหรับภาพดาวเทียม)
- หรือเปิดผ่าน GitHub Pages: Settings → Pages → Deploy from a branch → main / root

## ไลบรารีที่ใช้ (โหลดจาก CDN)
- Leaflet 1.9.4, Leaflet.draw 1.0.4, JSZip 3.10.1
- ภาพดาวเทียม: Esri World Imagery · แผนที่ถนน: OpenStreetMap

## หมายเหตุ
- ใช้เพื่อการวิจัยและการศึกษา · ผู้บินต้องปฏิบัติตามกฎ กพท. และตรวจสอบพื้นที่ก่อนบินทุกครั้ง
